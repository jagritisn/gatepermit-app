# Jobs-to-be-done: Gate Security

See [`product/roles/gate-security.md`](../roles/gate-security.md) for the full role profile.

1. When a visitor arrives at the gate, I want to verify their pass instantly, so I can let valid visitors through without delay.

2. When a pass is expired, already used, or invalid, I want a clear rejection signal, so I don't mistakenly admit someone without a valid permit.

3. When the verification system is down or a visitor lacks a working device, I want a manual fallback process, so I can still verify entry without stopping the flow of legitimate visitors.

4. When I've verified a visitor, I want the entry logged automatically, so there's a record without extra paperwork on my end.

5. When I'm uncertain about a pass's validity, I want to escalate to a supervisor or the Approving Officer, so I don't make an unauthorized entry decision alone.
