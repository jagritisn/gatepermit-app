# Jobs-to-be-done: Facility Admin

See [`product/roles/facility-admin.md`](../roles/facility-admin.md) for the full role profile.

1. When setting up the system for our office, I want to configure visiting hours, capacity, and permit rules, so the app enforces our office's actual policies.

2. When staff turnover happens, I want to manage Approving Officer and Gate Security accounts, so access stays current and secure.

3. When I need to understand how the office is being used, I want to view logs and analytics on requests, approvals, and gate entries, so I can report on operations and spot issues.

4. When the normal digital flow fails, I want tools to manually override or verify entry, so operations don't halt during an outage.

5. When compliance is questioned, I want to confirm the system stores only simulated, demo identity data and never real biometric or citizen records, so the office stays within its privacy mandate.
