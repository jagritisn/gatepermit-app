# Design Context

This project has `PRODUCT.md` and `DESIGN.md` (seed) at the repo root — read them before making UI/UX decisions.

- **Register:** product (app/tool, not marketing)
- **What it is:** Entry-permit web app for government office visitors — request a permit, track status, present the approved pass at the gate.
- **Personality:** efficient, minimal, contemporary — explicitly avoid the bureaucratic-gov-portal look and consumer-app gloss.
- **Non-negotiables:** WCAG 2.1 AA, plain language, multi-language support, one task per screen.

See [PRODUCT.md](PRODUCT.md) and [DESIGN.md](DESIGN.md) for full detail. The Next.js app lives in `app/`.
